14) Patch laplace-torch for compatibility with curvlinops 3.x

    curvlinops 3.x renamed curvlinops._base -> curvlinops._torch_base.
    Patch line 15 of:
    D:\anaconda3\envs\c4_class\Lib\site-packages\laplace\curvature\curvlinops.py

    Replace:
        from curvlinops._base import _LinearOperator

    With:
        try:
            from curvlinops._base import _LinearOperator
        except ImportError:
            from curvlinops._torch_base import PyTorchLinearOperator as _LinearOperator

    Use the following Python one-liner (from the fix_laplace.py temp script approach):

$script = @'
import re
path = r'D:\anaconda3\envs\c4_class\Lib\site-packages\laplace\curvature\curvlinops.py'
with open(path, 'r', encoding='utf-8') as f:
    content = f.read()
content = content.replace(
    'from curvlinops._base import _LinearOperator',
    'try:\n    from curvlinops._base import _LinearOperator\nexcept ImportError:\n    from curvlinops._torch_base import PyTorchLinearOperator as _LinearOperator'
)
with open(path, 'w', encoding='utf-8') as f:
    f.write(content)
print('done')
'@
$script | Out-File -FilePath "$env:TEMP\fix_laplace.py" -Encoding utf8
D:\anaconda3\envs\c4_class\python.exe "$env:TEMP\fix_laplace.py"

15) Patch laplace-torch baselaplace.py to make asdfghjkl import optional

    The installed asdl/asdfghjkl 0.1a4 package has an incompatible API with what
    laplace 0.2.2.2 expects (hessian_eigenvalues renamed, etc.). The AsdfghjklHessian
    backend is not needed for c4 inference — make it an optional import.

    Edit:
    D:\anaconda3\envs\c4_class\Lib\site-packages\laplace\baselaplace.py

    Replace line 18:
        from laplace.curvature.asdfghjkl import AsdfghjklHessian

    With:
        try:
            from laplace.curvature.asdfghjkl import AsdfghjklHessian
        except (ImportError, ModuleNotFoundError):
            AsdfghjklHessian = None
